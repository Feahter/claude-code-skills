# 失效模式：服务端接口

适用：HTTP API / RPC / GraphQL / 接口契约的变更。

## 失效模式清单

### 契约与兼容

- **字段语义漂移**：字段名没变，含义变了（`status` 从字符串枚举变数字）
- **可选变必填**：老客户端不传该字段，直接 400
- **枚举新增**：客户端 switch 没有 default，遇到新值崩或走错分支
- **类型收窄**：`string | number` 变成只接受 number
- **废弃字段仍被依赖**：删了字段但有调用方在读
- **默认值变更**：不传参时的行为变了
- **分页结构变更**：offset 换 cursor，老调用方翻不了页

### 鉴权与越权

- **水平越权（IDOR）**：把资源 id 换成他人的，能读能改
- **垂直越权**：普通用户调管理接口
- **鉴权缺失**：新加的接口忘了挂中间件
- **权限缓存滞后**：权限被收回后旧 token 仍生效多久
- **鉴权与业务校验顺序**：先查数据再判权限，导致「无权限但通过报错内容推断出资源存在」
- **越权的静默形式**：返回 200 + 空数据（看起来安全，实际上可枚举资源是否存在）

### 输入处理

- 边界值：0、负数、极大值、空字符串、null 与字段缺失的区别
- 类型混淆：字符串 `"1"` 与数字 `1`；数组传单值
- 超长输入、深层嵌套 JSON（解析炸栈 / 拒绝服务）
- 注入面：SQL / NoSQL / 命令 / 模板 / 路径穿越
- 编码：URL 编码、Unicode 规范化、大小写敏感性
- 批量接口：数组里部分元素非法时是整体拒绝还是部分成功

### 错误与部分失败

- **错误码语义**：客户端靠 code 分支，code 变了或复用了
- **错误信息泄露**：堆栈、SQL、内部路径、他人数据出现在错误体里
- **部分成功**：批量操作一半成功一半失败，返回 200 还是 207，客户端怎么知道哪些失败
- **超时后的真实状态**：客户端超时了但服务端其实成功了（这是重复提交的主要来源）

### 幂等与重试

- 写接口无幂等键，重试产生多条
- 幂等键作用域错（按用户维度还是按请求维度）
- 幂等记录过期时间与业务重试窗口不匹配

### 分页排序与性能面

- 排序不稳定（排序键有重复值且无 tie-breaker）→ 翻页重复或漏数据
- 深分页性能塌陷
- 游标失效（游标指向的记录被删）
- N+1 查询（功能对但一次请求打几百条 SQL）

## 常用 oracle

| 风险类型 | oracle 取向 |
|---|---|
| 契约兼容 | **契约校验**：响应体过 schema 校验；老版本请求样本仍能通过 |
| 越权 | **必须失败**：非本人 / 非授权角色请求返回 403 且响应体不含目标数据 |
| 幂等 | **副作用计数**：同一幂等键重复请求 N 次，落库记录数 == 1，且返回体一致 |
| 部分失败 | **不变量**：失败元素不产生副作用，成功元素的副作用完整；响应能逐项区分 |
| 错误码 | **精确匹配**：错误码与文档一致，不接受「返回了某个 4xx」 |
| 排序分页 | **不变量**：全量翻页拿到的集合 == 一次性全量查询的集合，无重复无遗漏 |
| 输入边界 | **必须失败** + 无副作用：非法输入被拒且不落库、不留脏数据 |
| 信息泄露 | **属性断言**：错误响应体不含堆栈 / SQL / 内部路径关键字 |

## 证据来源

| 要找什么 | 去哪找 |
|---|---|
| 接口定义与鉴权 | 路由注册、controller 装饰器、中间件挂载顺序、OpenAPI / proto 文件 |
| 入参约束 | DTO / validation schema / 参数解析层 |
| 幂等实现 | 幂等键表、Redis key 命名、唯一索引 |
| 事务边界 | 事务注解 / `BEGIN` 所在层、跨服务调用是否在事务内 |
| 调用方 | codebase-memory `trace_path` cross_service 模式查 Route 节点；网关配置；客户端代码 |
| 契约变更历史 | schema / proto 文件的 `git log`，对比字段增删 |

**鉴权判断特别提醒**：中间件的挂载顺序决定实际生效情况，只看装饰器不够，要确认路由注册顺序与全局中间件的覆盖范围。

## 可测试性阻塞信号

- 造不出特定角色 / 权限的凭证 → 越权类风险无法验，标 `testability_gap`，考虑先补测试用的授权工具
- 测试环境与生产的鉴权配置不同 → 越权测试结论不可迁移，明确写进不覆盖范围
- 无法观察落库结果（只能看接口返回）→ 副作用计数类 oracle 失效，需要补可观测出口
- 外部依赖无 sandbox 且不可 mock → 相关路径只能 `monitor`，不是 `test`

契约测试与 mock 的具体实现方案归 `playbook/references/contracts.md` 与 `playbook/references/mocking.md`。
