# 失效模式：Web 前端

适用：UI / 交互 / 表单 / 路由 / 前端状态管理的变更。

## 失效模式清单

对照本次变更逐条问「有没有东西让它成为可能」。找不到证据的丢掉，别为凑数留。

### 时序与竞态

- **请求后发先至**：连续切换筛选条件，先发的请求后返回，覆盖了新结果
- **卸载后写状态**：组件已卸载，异步回调还在 setState
- **防抖节流边界**：最后一次输入被吞掉；节流窗口内的关键操作丢失
- **轮询叠加**：页面切回来又起一个轮询，两个并存
- **乐观更新回滚失败**：本地先改了 UI，请求失败后没回滚，界面与后端不一致
- **重复提交**：按钮无禁用 / 无幂等键，双击产生两条记录

### 状态与数据

- **旧数据被当新数据**：缓存（SWR / react-query / store）返回 stale 值且没有重新验证
- **分页累积错误**：翻页时数据重复或漏掉；下拉加载 key 重复导致渲染错乱
- **跨页状态残留**：上一个详情页的数据闪现在下一个详情页
- **刷新丢状态**：多步流程刷新后回到第一步且已提交的数据丢了
- **派生状态不同步**：同一份数据两处各自计算，结果不一致

### 表单与输入

- **前端校验被绕过**：改请求直接提交，后端是否也拦
- **精度**：金额用浮点算，`0.1+0.2`；大整数超 `Number.MAX_SAFE_INTEGER`
- **字符与长度**：超长文本、emoji（代理对被截断）、首尾空格、全角半角、换行
- **输入法与自动填充**：中文输入法组合期触发校验；浏览器自动填充绕过 onChange
- **粘贴**：粘贴大段内容绕过逐字校验
- **必填与默认值**：默认值被当成用户输入提交；清空后提交的是空串还是 null

### 路由与权限

- **直连 URL 绕过入口**：菜单藏了但路由还在，直接输地址能进
- **深链接鉴权**：未登录直接访问详情页的处理
- **前进后退**：浏览器返回后表单状态 / 已提交状态是否正确
- **参数篡改**：把 URL 里的 id 改成他人的资源

### 渲染与呈现

- **三态缺失**：加载中 / 空 / 错误 三种状态里缺一个（最常缺错误态）
- **i18n**：缺 key 显示原始键名；复数与占位符顺序；文案变长导致布局破裂
- **时区与格式**：UTC 与本地时间混用；跨零点的日期显示
- **超长与溢出**：长名字、无空格长串、深层嵌套
- **资源失败**：图片 / 字体 / 懒加载 chunk 加载失败时的降级

### 可访问性与兼容

- 键盘可达性与 focus 陷阱（弹窗打开后 tab 跑到背景）
- 触屏与鼠标交互差异（hover 才出现的操作在触屏不可达）
- 视口极端宽度、系统深浅色模式

## 常用 oracle

| 风险类型 | oracle 取向 |
|---|---|
| 重复提交 | **副作用计数**：后端记录数 == 1 |
| 竞态覆盖 | **最终一致**：快速切换 N 次后，界面显示的必须是最后一次请求的结果 |
| 乐观更新 | **往返一致**：请求失败后界面值 == 操作前的值 |
| 前端校验绕过 | **必须失败**：直接构造非法请求，后端返回拒绝且不落库 |
| 权限 | **必须失败**：越权访问返回 403 / 跳转，且不泄露数据体 |
| 精度 | **参照对照**：与后端返回的权威值逐位比对 |
| 三态 | **可观察信号**：每种状态有可断言的标识，不是靠截图看 |

细则见 `oracle-patterns.md`。断言怎么写归 `playbook/references/assertions.md`。

## 证据来源

| 要找什么 | 去哪找 |
|---|---|
| 路由与权限入口 | 路由配置文件、菜单配置、路由守卫 / middleware |
| 请求与缓存策略 | 请求层封装、react-query / SWR 的 staleTime 与 key、拦截器 |
| 表单校验规则 | zod / yup / rules schema、提交处理函数 |
| 状态管理 | store 定义、selector、持久化配置（是否 persist 到 localStorage） |
| 影响面 | 该组件被谁引用（codebase-memory `trace_path` inbound）、是否在核心路由下 |
| 历史高发 | `git log --grep='fix\|hotfix' -- <组件路径>` |

## 可测试性阻塞信号

出现这些，**不要硬写测试**，产出 `testability_gap` 并考虑 `design-fix` 处置：

- 渲染必须 mock 一大坨依赖才跑得起来 → 组件边界过宽
- 只能断言 className / 内部 store 才能验证 → 缺少用户可感知的输出
- 交互节点没有语义锚点，只能退到 `nth-child` / 动态 className → 缺可访问名
- 时序问题只能靠 `sleep` 才能复现 → 缺可观测的状态信号
